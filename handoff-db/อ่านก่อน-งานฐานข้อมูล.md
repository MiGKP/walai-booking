# งานฐานข้อมูลที่ต้องทำก่อนเปิดระบบ (ฉบับสั้น)

## ทำไมต้องทำ
โค้ดหลังบ้านใหม่ใช้คอลัมน์ในฐานข้อมูลที่ยังไม่มี ถ้าไม่เพิ่มให้ครบ บางหน้าจะขึ้น error หรือระบบล็อกอินพัง

## ต้องทำ 3 เรื่อง

**1. เพิ่มคอลัมน์ที่ขาด**
- ใช้ไฟล์ `04-migration-missing-columns.sql`
- ทำบน **สำเนาฐานข้อมูล (branch สำรอง)** ก่อน แล้วค่อยทำบนของจริง
- ทำแค่ครั้งเดียว รันซ้ำก็ไม่เสียหาย

**2. เพิ่มคอลัมน์เรื่องความปลอดภัย**
- ใช้ไฟล์ `05-migration-security-hardening.sql`
- **ทำเสร็จแล้วต้องให้คนพัฒนา deploy หลังบ้านใหม่ทันที** ถ้าไม่ deploy ผู้ใช้ที่ล็อกอินอยู่จะเจอ error

**3. ตรวจว่ามีข้อมูลรีสอร์ท** อันนนี้มีดูมาแล้ว
- ใช้ไฟล์ `02-check-resort-row.sql`
- ต้องมีแถวที่ id = 3 ถ้าไม่มี หน้าแรกจะไม่มีเบอร์และเลขบัญชี

## ไฟล์ที่เหลือ
- `01`, `03`, `06` เป็นแค่การดูข้อมูล ไม่แก้อะไร
- `07` ใช้ทดสอบบน staging เท่านั้น **ห้ามรันบนของจริง**

## ลำดับ
01 → 02 → 03 → (สำรองข้อมูล) → 04 → 05 → deploy หลังบ้าน → 06

## ถ้าไม่แน่ใจ
อย่ารันเอง ให้ถามคนพัฒนาก่อนเสมอ
